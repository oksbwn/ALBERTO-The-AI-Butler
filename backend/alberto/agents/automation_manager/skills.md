# Automation Manager Skills & Low-Code Authoring Guide

## Core Capabilities
1. **Workflow Proposal Generation**: Translate natural-language requirements into validated workflow proposals (`single_agent`, `multi_agent`, `deterministic`, or `hybrid` strategy) via `delegate_automation_management`.
2. **Low-Code Graph & Canvas Alignment**: Generate both executable LangGraph definitions (`nodes`, `edges`, `state`, `entry_node`) and positioned React Flow canvas layouts.
3. **Bounded Self-Correction & Safe Dry-Run Testing**: Validate state declarations, node schemas, and router edges, and execute dry-run graph simulations prior to activation.
4. **Failure Diagnosis & Monitoring**: Inspect failed or interrupted runs, identify the slowest or failing node, and propose safe configuration repairs.
